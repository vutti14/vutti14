**รวมประมาณ 8 MB ต่อการเปิดหน้าแรก 1 ครั้ง และประมาณ 5 MB ในนั้นคือรูปที่ผู้ใช้ไม่เห็นด้วยซ้ำ**

บนเน็ตมือถือ 4G ในไทย (ประมาณ 10–20 Mbps จริง) นั่นคือรอ **6–12 วินาที**
Google ตั้งเกณฑ์ LCP ที่ "ดี" ไว้ที่ **ไม่เกิน 2.5 วินาที**

2 อย่างนี้แก้แยกกัน:
1. **รูปที่ไม่ได้แสดง (~5 MB)** → แก้ด้วย `patch/custom.js` ไม่ต้องแตะรูป
2. **รูปที่แสดงจริงแต่ใหญ่เกิน (~3 MB)** → แก้ด้วยการอัปโหลดไฟล์ในโฟลเดอร์นี้ทับ
