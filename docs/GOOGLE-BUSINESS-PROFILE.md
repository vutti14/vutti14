# ชุดตั้ง Google Business Profile — ทั้งสองที่

## สรุปสั้น

ผมทำแทนไม่ได้ เพราะต้องล็อกอินด้วยบัญชี Google ของคุณและต้องยืนยันความเป็นเจ้าของสถานที่
แต่ผมเตรียมทุกอย่างที่ต้องกรอกไว้ให้แล้ว **ก๊อบวางได้เลยทุกช่อง**

**และเจอปัญหาหนึ่งที่ต้องแก้ก่อน ไม่งั้นข้อนี้จะพัง:**

> **หน้าติดต่อของ silalang.com ไม่มีที่อยู่เลย** — ช่อง “ที่อยู่ของร้าน” ว่างเปล่า มีแค่เบอร์กับอีเมล
> **และที่อยู่ของ หินอ่อน.com ไม่มีชื่อจังหวัด**

Google เอาที่อยู่บนเว็บมาเทียบกับที่อยู่ใน Business Profile ถ้าไม่ตรงกันหรือหาไม่เจอ
การยืนยันจะช้าลงและความน่าเชื่อถือของโปรไฟล์จะต่ำลง **ต้องเติมที่อยู่บนเว็บก่อน**

## ขั้นที่ 0 — เติมที่อยู่บนเว็บก่อน (15 นาที)

### silalang.com → หน้า ติดต่อเรา → ช่อง “ที่อยู่ของร้าน”

ตอนนี้ว่างเปล่า ต้องใส่ที่อยู่จริงของเหมือง รูปแบบที่ Google อ่านง่ายที่สุด:

```
[บ้านเลขที่ หมู่ที่]
ตำบล[___] อำเภอ[___]
จังหวัดกำแพงเพชร [รหัสไปรษณีย์]
```

**ผมกรอกแทนไม่ได้เพราะไม่รู้ที่ตั้งจริงของเหมือง** — ต้องเป็นคุณ
ใช้ที่อยู่ตามประทานบัตรหรือตามที่รถส่งของใช้จริง อย่าใช้ที่อยู่บ้าน

### หินอ่อน.com → เติมชื่อจังหวัด

ตอนนี้เป็น:
```
700 ถนนศรีนครินทร์
แขวงหนองบอน  เขตประเวศ
10250
```

แก้เป็น:
```
700 ถนนศรีนครินทร์ แขวงหนองบอน
เขตประเวศ กรุงเทพมหานคร 10250
```

ที่แก้: เติม **กรุงเทพมหานคร** และเอาช่องว่างซ้อนออก

## ขั้นที่ 4 — ขอรีวิว

### หาลิงก์รีวิวของคุณ
business.google.com → เลือกโปรไฟล์ → **ขอรีวิว** → คัดลอกลิงก์ที่ได้
(หน้าตาแบบ `https://g.page/r/XXXXXXXX/review`) **ทำแยกกันสองโปรไฟล์**

### เวลาที่ควรขอ
- **ศิลาแลง / หินปูพื้น** → 3–7 วันหลังติดตั้งเสร็จ
- **พระบูชา** → 1–2 สัปดาห์หลังรับของ ให้เขาได้ตั้งบนหิ้งแล้ว
- **อย่าขอตอนเพิ่งโอนเงิน** — ยังไม่เห็นของ รีวิวจะกลวง

### ข้อความที่ใช้ขอ

```
สวัสดีครับคุณ [ชื่อ] ศิลาเพชรครับ
งานที่ [ชื่องาน] เรียบร้อยดีไหมครับ ถ้ามีอะไรไม่เรียบร้อยบอกได้เลยนะครับ

ถ้าพอใจ รบกวนช่วยรีวิวให้หน่อยได้ไหมครับ ใช้เวลาไม่ถึงนาที
[ลิงก์รีวิว]

ถ้าแนบรูปงานที่ติดตั้งแล้วมาด้วยจะดีมากครับ
เพราะลูกค้าคนอื่นอยากเห็นของจริงมากกว่ารูปในเว็บ
```

**ถามเรื่องงานก่อน ไม่ใช่ขอรีวิวทันที** — เปิดช่องให้เขาบ่นกับคุณแทนที่จะไปบ่นในรีวิว

### ห้ามทำ
- ❌ ซื้อรีวิว — Google ลบและอาจปิดโปรไฟล์ถาวร
- ❌ ให้ส่วนลดแลกรีวิว 5 ดาว — ผิดนโยบายชัดเจน
- ❌ ลบหรือซ่อนรีวิวแย่ — **4.6 ที่มีรีวิว 3 ดาวปนบ้าง น่าเชื่อกว่า 5.0 ที่สมบูรณ์แบบเกินไป**
- ✅ **ตอบทุกรีวิว รวมรีวิวแย่** — Google ให้น้ำหนัก และคนอ่านดูว่าคุณตอบยังไง
