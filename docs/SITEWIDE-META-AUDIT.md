# ตรวจทั้งเว็บ 330 หน้า — พบปัญหาใหญ่ที่ผมพลาดไปตอนแรก

*วัดจากเว็บจริง 6 ก.ย. 2026 · ดึงทุก URL จาก sitemap ทั้งสองเว็บแล้วอ่านทีละหน้า*

## สรุปสั้น

ก่อนหน้านี้ผมสุ่มดูแค่ไม่กี่หน้า รอบนี้ผมดึงมาครบทั้ง **330 หน้า** แล้วเจอสองเรื่องที่ใหญ่กว่าทุกอย่างที่เคยรายงานไป:

> **1. `<title>` ทุกหน้าบนทั้งสองเว็บยาวเกินที่ Google แสดง — 330 จาก 330 หน้า**
> **2. หน้าบน หินอ่อน.com 122 หน้าจาก 214 ใช้ meta description ข้อความเดียวกันเป๊ะ**

ทั้งสองข้อแก้ได้ด้วยการก๊อบวาง ไม่ต้องเขียนโค้ด และผมทำไฟล์ให้ครบทุกหน้าแล้ว

## 1. title ยาวเกินทุกหน้า

| | หินอ่อน.com | silalang.com |
|---|---|---|
| หน้าทั้งหมด | 214 | 116 |
| title ยาวเกิน 60 ตัวอักษร | **214 (100%)** | **116 (100%)** |
| ความยาวเฉลี่ย | **106 ตัวอักษร** | **111 ตัวอักษร** |
| มีคำต่อท้าย `: Inspired by LnwShop.com (v2)` | 214 (100%) | 116 (100%) |

Google แสดง title ได้ราว 60 ตัวอักษร ที่เหลือถูกตัดทิ้งเป็น `…`

**และจุดที่แย่ที่สุดคือส่วนที่ถูกตัดทิ้ง มักเป็นส่วนที่บอกว่าหน้านั้นต่างจากหน้าอื่นยังไง** เช่น:

```
หินอ่อนขาวหิมาลัย Himalayan White Marble 30x60 ซม. - หินอ่อน.com | SIAM STONE ... : Inspired by LnwShop.com (v2)
                                         ^^^^^^^^^^ ส่วนสำคัญอยู่ตรงนี้ แต่ Google ตัดตั้งแต่ก่อนถึง
```

ทั้ง 3 ขนาดของหินตัวเดียวกัน (30×60 / 60×60 / ทุกขนาด) จึงขึ้นใน Google เป็นข้อความที่**อ่านแล้วเหมือนกันหมด**
คนค้นหา "หินอ่อนขาวหิมาลัย 60x60" เห็นสามบรรทัดเหมือนกัน ไม่รู้จะกดอันไหน

**ถ้าตัดแค่คำต่อท้าย LnwShop ออก** ความยาวเฉลี่ยลดจาก 106 → 75 ซึ่ง**ยังเกินอยู่ 161 จาก 214 หน้า** — ต้องเขียนใหม่ ไม่ใช่แค่ตัดท้าย

## 2. meta description ซ้ำกัน

| | หินอ่อน.com | silalang.com |
|---|---|---|
| หน้าที่ description ซ้ำกับหน้าอื่น | **122 จาก 214 (57%)** | 35 จาก 116 (30%) |
| กลุ่มที่ใหญ่ที่สุด | **122 หน้าใช้ข้อความเดียวกัน** | 23 หน้าใช้ข้อความเดียวกัน |

ข้อความที่ซ้ำ 122 หน้าบน หินอ่อน.com:

> *"แผ่นหินอ่อน หินแกรนิต ตัดตามขนาด จาก SIAM STONE โทร 065-567-8989 และ 062-559-9000..."*

ในนั้นมี **หน้าสินค้า 95 หน้า** — คือหน้าที่ควรจะแตกต่างกันมากที่สุดกลับเหมือนกันหมด
รวมถึงหน้าแรก หน้าเกี่ยวกับเรา หน้าติดต่อ และหน้าแจ้งชำระเงิน ก็ใช้ข้อความเดียวกันนี้

**ทำไมถึงสำคัญ:** description คือข้อความที่คนอ่านใน Google ก่อนตัดสินใจกด
122 หน้าที่พูดเหมือนกันหมด แปลว่า 122 หน้านั้นไม่มีเหตุผลให้ใครกดสักหน้า

## 3. ปัญหาอื่นที่เจอ

| ปัญหา | หินอ่อน.com | silalang.com |
|---|---|---|
| รูปที่ `alt` ว่างหรือไม่มี | **1,530 จาก 5,108 (30%)** | **1,073 จาก 2,135 (50%)** |
| หน้าที่ไม่มี H1 | 1 | 0 |
| หน้าที่มี H1 มากกว่า 1 อัน | 4 | 5 |
| HTTP ไม่ใช่ 200 | 0 ✅ | 0 ✅ |

### ⚠️ description ลอกมาจากวิกิพีเดีย — 2 หน้าบน silalang.com

- `/article/1/เหมือง-ศิลาแลง`
- `/category/8/เหมืองศิลาแลง-ของเรา-เหมืองศิลาเพชร/เหมือง-ศิลาเพชรของเราเอง-ครับ`

ทั้งสองหน้าใช้ description ที่ขึ้นต้นว่า *"ศิลาแลง จากวิกิพีเดีย สารานุกรมเสรี..."*

**นี่คือปัญหาสองชั้น:** Google รู้ว่าข้อความนี้เป็นของวิกิพีเดียและจะไม่ให้อันดับกับหน้าที่ลอกมา
และหน้า `/category/8/` คือหน้าที่ควรจะเป็นจุดขายที่แข็งที่สุดของคุณ — **หน้าเหมืองของตัวเอง**
กลับใช้ข้อความที่ลอกจากสารานุกรม ทั้งที่คุณมีเรื่องเล่าจากของจริงที่ไม่มีใครมี

### ⚠️ description หนึ่งกลุ่มขึ้นต้นด้วย `| ` — 2 หน้าบน silalang.com

เป็นอักขระค้างจากตอนตั้งค่า ไม่มีผลกับอันดับ แต่ทำให้ข้อความใน Google ขึ้นต้นด้วยขีดคั่นแปลก ๆ

### ⚠️ silalang.com มี `WebSite` JSON-LD อยู่แล้ว

หน้าเว็บจริงมี `@type: WebSite` พร้อม `SearchAction` ติดมากับ LnwShop อยู่แล้ว
**ผมเคยใส่บล็อก WebSite ซ้ำเข้าไปใน `patch-silalang/head-snippet.html` ซึ่งจะทำให้มีสองอันในหน้าเดียว — แก้แล้ว**
ส่วน หินอ่อน.com ตรวจแล้วไม่มี จึงคงบล็อก WebSite ใน `patch/head-snippet.html` ไว้ตามเดิม

## 4. ของที่ทำให้แล้ว — ครบทั้ง 330 หน้า

| ไฟล์ | มีอะไร |
|---|---|
| `content/meta-all-pages.csv` | หินอ่อน.com **214 หน้า** — title ใหม่ + description ใหม่ ทีละหน้า |
| `content-silalang/meta-all-pages.csv` | silalang.com **116 หน้า** — เหมือนกัน |

ทั้งสองไฟล์มีคอลัมน์ `title เดิม` และ `description เดิม` ให้เทียบข้าง ๆ กัน

### ผลหลังเขียนใหม่

| | หินอ่อน.com | silalang.com |
|---|---|---|
| title ยาวเฉลี่ย | 106 → **37** | 111 → **45** |
| title เกิน 60 | 214 → **0** | 116 → **0** |
| **title ซ้ำกัน** | → **0** | → 4 (คือสินค้าซ้ำจริง 2 คู่ ที่ควรลบทิ้ง ไม่ใช่เปลี่ยนชื่อ) |
| description ยาวเฉลี่ย | 113 → **135** | 91 → **131** |
| description เกิน 160 | → **0** | → **0** |
| **description ซ้ำกัน** | 122 → **0** | 35 → **0** |

**ไม่มี description ซ้ำกันแม้แต่หน้าเดียวบนทั้งสองเว็บ** — ตรวจด้วยการนับข้อความที่ตรงกันทุกตัวอักษร

### วิธีที่ผมใช้เขียน

- **หน้าสินค้า** — ย่อจากคำอธิบายสินค้าที่เขียนไว้แล้ว (55 + 65 ชิ้น) จึงตรงกับสินค้าชิ้นนั้นจริง
- **หน้าบทความและ tag** — สร้างจากชื่อเรื่องของหน้านั้นเอง
- **หน้าหมวดหมู่** — ระบุว่าในหมวดมีอะไร
- **หน้าคงที่** (เกี่ยวกับเรา ติดต่อ วิธีสั่ง แจ้งชำระเงิน) — เขียนมือทีละหน้า
- **title ที่ยาวเกิน** — ตัดหัวเรื่องที่ซ้ำกันออก แต่**เก็บส่วนท้ายที่ทำให้ต่างกันไว้เสมอ** (ขนาด ผิว สี ชื่อเมือง)
