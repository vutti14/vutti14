## สิ่งที่ทำไว้ดีแล้ว (อย่าไปรื้อ)

- **Product schema ครบ** — ชื่อ, รูป, SKU, ราคา, `availability`, `priceValidUntil` ถูกต้องตามมาตรฐาน
- **BreadcrumbList** ครบทุกหน้าสินค้า
- **canonical + hreflang th** ถูกต้อง ไม่มี URL ซ้ำ
- **sitemap.xml** แยกเป็น sitemap index ต่อหมวด ทำงานปกติ
- **robots.txt** ตั้งใจบล็อก AhrefsBot / MJ12bot / BLEXBot — ถูกต้องแล้ว
  (แต่บล็อก **Applebot** ด้วย = หายจาก Siri และ Spotlight, และบล็อก **Yandex** ทั้งตัว
  ถ้าไม่ได้ตั้งใจ ควรทบทวน)
- **หน้าสินค้าบนมือถือ** ใช้งานได้จริง มีปุ่มโทร / Messenger / LINE ชัดเจน
- **เนื้อหาบทความ 27 ชิ้น** — นี่คือทรัพย์สินที่คู่แข่งลอกไม่ได้ในวันเดียว
- **โดเมนภาษาไทย หินอ่อน.com** — จำง่ายมาก ได้เปรียบเรื่อง brand recall
- **ไม่มี horizontal scroll บนมือถือ** — ตรวจแล้วทุกหน้ากว้าง 390 px พอดี ไม่ล้น

## ปัญหาเรียงตามผลกระทบ

### 1. รูปภาพ — ปัญหาที่ใหญ่ที่สุด และแก้ง่ายที่สุด

วัดจาก Chromium จริงที่หน้าจอ 390×844 px:

| รูป | ขนาดไฟล์ | ขนาดจริง | แสดงผลจริง |
|---|---|---|---|
| `_raw/he/a1/fv.jpg` | 3.05 MB | 2480 × 3508 | 370 × 523 |
| `_raw/uz/6q/8q.jpg` | 3.65 MB | 2480 × 3508 | **0 × 0** |
| `_raw/4f/jo/zk.jpg` | 0.53 MB | 1920 × 450 | **0 × 0** |
| `_raw/di/4r/lm.jpg` | ~0.4 MB | 1706 × 960 | **0 × 0** |
| `_raw/8k/xf/o2.jpg` | ~0.4 MB | 1706 × 960 | **0 × 0** |

- ไม่มีรูปไหนตั้ง `loading="lazy"` เลย (ทุกตัวเป็น `auto`)
- รูปตารางราคา 2480×3508 px คือขนาดกระดาษ A4 ที่ 300 DPI — เป็นไฟล์สำหรับ **สั่งพิมพ์** ไม่ใช่สำหรับเว็บ
- รูปไม่มี `alt`: หน้าแรก 4 จาก 45 (มือถือ), **หน้าหมวดหมู่ 12 จาก 36**

**แก้:** `patch/custom.js` (จัดการรูปที่ไม่แสดง) + `assets/optimized/` (อัปโหลดทับ)
**ผลที่คาด:** หน้าแรกจาก ~8 MB เหลือ ~1.5 MB

### 2. ราคาอยู่ในรูปภาพ

ตารางราคาทั้งหมด — Himalayan White, White Vincente, White Pearl 3 ผิว —
อยู่ในไฟล์ JPEG ไฟล์เดียว ไม่มีข้อความ HTML รองรับเลย

ผลที่ตามมา:

- คำค้นแบบ `"หินแกรนิตขาวไข่มุก ราคา"`, `"ราคาหินอ่อน ตร.ม."`, `"หินแกรนิต 60x60 ราคา"`
  — เว็บนี้ไม่มีข้อความพวกนี้อยู่เลยแม้แต่คำเดียว นี่คือกลุ่มคำค้นที่ **คนกำลังจะซื้อ** ใช้
- คนบนมือถือต้องซูมอ่าน = แรงเสียดทานสูง
- เวลาขึ้นราคา ต้องจ้างทำรูปใหม่ — ซึ่งเป็นเหตุผลว่าทำไมรูปยังเขียน **"price update 2024"**
  อยู่ในเดือนกันยายน 2026 (ราคาเก่า 2 ปี = ลูกค้าโทรมาแล้วเจอราคาไม่ตรง = เสียความน่าเชื่อถือ)

**แก้:** `content/price-table.html` (ผมถอดตัวเลขจากรูปให้แล้วครบทุกตาราง)

### 3. โครงสร้างหัวเรื่อง (Heading)

หน้าแรก (นับจาก DOM ที่ render แล้ว):

```
เดสก์ท็อป  h1: 0   h2: 0   h3: 8
มือถือ     h1: 0   h2: 1   h3: 8   ("หมวดหมู่" เป็น h2 ตัวเดียวที่มี)

h3 ที่มี: RECOMMENDED ITEMS, ติดต่อเรา, Search, หมวดหมู่สินค้า,
          NEW AVAILABLE, ระบบสมาชิก, เว็บเพื่อนบ้าน, สถิติร้านค้า
```

หน้าหมวดหมู่และหน้าบทความมี `h1` ถูกต้อง — ปัญหาอยู่ที่หน้าแรกหน้าเดียว
แต่หน้าแรกคือหน้าที่รับลิงก์เข้ามามากที่สุดและถูกใช้ตัดสิน "เว็บนี้เกี่ยวกับอะไร"

หัวเรื่องที่มีก็ไม่ช่วย: `"RECOMMENDED ITEMS"` และ `"NEW AVAILABLE"` เป็นภาษาอังกฤษ
บนเว็บที่ลูกค้าเป็นคนไทย 100% — ทั้งเสีย SEO และเสีย UX

**แก้:** `content/home-hero.html` วางเป็น Gadget HTML บนสุดของหน้าแรก

### 4. Analytics ตายมา 3 ปี

พบในหน้าเว็บ:

```
gtag('config', 'UA-18903793-17')   ← Universal Analytics หยุดเก็บข้อมูล 1 ก.ค. 2023
gtag('config', 'AW-10974181776')   ← Google Ads conversion tag (ยังทำงาน)
GTM-N3SX83RH                       ← Google Tag Manager (มีอยู่)
```

**ไม่พบ GA4 Measurement ID (`G-XXXXXXXXXX`) ทั้งในหน้าเว็บและใน GTM container**

ต้องเข้าไปยืนยันใน GTM/GA เอง เพราะจากภายนอกดูได้ไม่ครบ 100%
แต่ถ้าไม่มีจริง แปลว่าตั้งแต่กลางปี 2023 เป็นต้นมา คุณไม่มีข้อมูลว่า:
คนเข้ามาจากไหน หน้าไหนคนออกเยอะ คนที่โทรมาเข้ามาจากคำค้นอะไร

**แก้:** `patch/head-snippet.html` ส่วน [3]

### 5. Title ทุกหน้าถูกต่อท้ายด้วยโฆษณาของ LnwShop

```
FLEX STONE LIGHT TRAVERTINE แผ่นหินยืดหยุ่นติดผนัง - หินอ่อน.com | SIAM STONE
แผ่นหินอ่อน หินแกรนิต : Inspired by LnwShop.com (v2)
```

ยาว 130+ ตัวอักษร Google แสดงได้ประมาณ 60 — ที่เหลือถูกตัดทิ้ง
และ 78 ตัวอักษรท้ายคือ **ชื่อแบรนด์คนอื่น** ที่แปะอยู่บนผลการค้นหาของคุณ

**แก้:** ตั้งค่าร้านค้า → SEO → ย่อส่วนต่อท้ายเหลือ `หินอ่อน.com`
ส่วน `": Inspired by LnwShop.com (v2)"` ต้องถาม LnwShop ว่าปลดได้ที่แพ็กเกจไหน

### 7. เดสก์ท็อป: หน้าแรกเลื่อนออกไปทางขวาได้ 4,061 px

```
document.documentElement.clientWidth  = 1440
document.documentElement.scrollWidth  = 4061 (วัดครั้งที่ 1)
                                        2621 ส่วนเกิน (วัดครั้งที่ 2)
```

ตัวเลขไม่คงที่เพราะขึ้นกับว่า gadget ไหนโหลดทันตอนวัด แต่ **เกินทุกครั้ง**

ตัวการ: `div.zoneShirt` กว้าง 3,801 px ใน `#gadget-4.widgetZone.z-article`
ซึ่งเป็น **Gadget HTML ที่วางเองในหลังร้าน** ไม่ใช่ของ template

มือถือไม่มีปัญหานี้ (390 px พอดี) แต่บนคอมจะเห็น scrollbar แนวนอน
Google ระบุเป็นข้อผิดพลาด "Content wider than screen"

**แก้:** `patch/custom.css` บล็อก [1]

### 9. หน้าสินค้ามี 3 ปุ่มแข่งกัน

`ซื้อเลย` (ปุ่มทอง) / `หยิบลงตะกร้า` / `BUY NOW` วางเรียงกันในจอเดียว
ลูกค้าที่เห็น 3 ทางเลือกที่ดูเหมือนกันจะลังเล — และธุรกิจนี้จริง ๆ แล้วปิดการขายทางโทรศัพท์

คำถามที่ควรตอบก่อนแก้: **เว็บนี้ต้องการให้คน "ซื้อออนไลน์" หรือ "โทรมา"?**
ถ้าคำตอบคือโทรมา ปุ่มที่ควรเด่นที่สุดคือ `โทร` และ `LINE` ไม่ใช่ `ซื้อเลย`
ตอนนี้เว็บยังตอบคำถามนี้ไม่ชัด และการออกแบบก็สะท้อนความไม่ชัดนั้น

### 10. บทความ 27 ชิ้นถูกใช้งานไม่คุ้ม

บทความที่มีอยู่ดีมาก — `"ท็อปครัวหินอ่อนขาว vs หินแกรนิตสีเข้ม เลือกยังไง"`,
`"วิธีทำความสะอาดและบำรุงรักษาหินอ่อน"`, `"หินอ่อนปูพื้นวัด"` — ตรงกับสิ่งที่คนค้นจริง

แต่:
- หน้า `/article` render รายชื่อบทความด้วย JavaScript ทั้งหมด — ใน HTML ดิบไม่มีลิงก์บทความเลย
  Google อ่านได้ แต่ช้ากว่าและเสี่ยงกว่า
- ไม่พบลิงก์จากบทความ → หน้าสินค้าที่เกี่ยวข้อง (บทความท็อปครัวควรลิงก์ไปหมวดหินแกรนิต)

  **69 หน้ามีสินค้าไม่เกิน 2 ชิ้น และ 61 หน้าในนั้นมีสินค้าชิ้นเดียว**
  เทียบกับสินค้าทั้งร้าน 55 ชิ้น = หน้า tag เกือบสองเท่าของจำนวนสินค้า
  ผลนับรายหน้าอยู่ใน `content/tag-audit.csv`

## คำถามที่ใหญ่กว่า UX/SEO — ควรตัดสินใจก่อนลงแรงเยอะ

คุณขอให้ผมทำ UX/UI และ SEO ให้ดีขึ้น ผมทำได้และทำมาให้แล้วในโฟลเดอร์นี้
แต่ผมจะไม่ทำเป็นไม่เห็นเพดานที่รออยู่ข้างหน้า:

**บน LnwShop คุณจะชนได้แค่ระดับหนึ่ง** เพราะสิ่งที่ตัดสินอันดับในปี 2026 —
Core Web Vitals, HTML ที่ render มาจากเซิร์ฟเวอร์, ความเร็วในการโหลด —
ส่วนใหญ่ถูกกำหนดโดย template ที่คุณแก้ไม่ได้ (jQuery ปี 2016, ไฟล์ Flash, CSS 1200px คงที่)

แต่ **อย่าเพิ่งย้าย** เหตุผล:

1. งานในโฟลเดอร์นี้กินเวลาไม่เกิน 1 วันทำ และให้ผลชัดวัดได้ ทำก่อน
2. ย้ายแพลตฟอร์มมีความเสี่ยง — 55 สินค้า, 27 บทความ, 110+ tag page
   ถ้า redirect พลาด อันดับที่สะสมมาหายทันที
3. **ตอนนี้คุณไม่มีข้อมูลพอจะตัดสินใจ** เพราะไม่มี Analytics มา 3 ปี

**ลำดับที่ผมแนะนำ:**

| ช่วง | ทำอะไร |
|---|---|

## สิ่งที่ผมยังตอบไม่ได้จากภายนอก

พูดตรง ๆ ว่ามีอะไรที่ผมมองไม่เห็น:

1. **อันดับปัจจุบัน** — ผมไม่มีสิทธิ์เข้า Search Console ของคุณ
   ผมเลยบอกไม่ได้ว่าตอนนี้ติดคำไหนอยู่ที่อันดับเท่าไร และคำไหนคือของตายที่ห้ามทำพัง
2. **GTM container** — ดูจากภายนอกไม่พบ GA4 tag แต่ยืนยัน 100% ไม่ได้ ต้องเปิดใน GTM ดูเอง
3. **ตัวเลข Core Web Vitals จากผู้ใช้จริง (CrUX)** — ต้องดูใน Search Console → Core Web Vitals
4. **หน่วยราคาในตาราง** — ผมกรอกเป็น "บาท/ตร.ม." จากที่อ่านในรูป ถ้าผิดต้องแก้
5. **เบอร์โทร 2 เบอร์** — `065-567-8989` กับ `062-559-9000` ปนกันทั้งเว็บ
   ควรเลือกเบอร์หลัก 1 เบอร์ให้สม่ำเสมอ (สำคัญกับ Local SEO เรื่อง NAP consistency)

ถ้าเปิดสิทธิ์ Search Console กับ GA ให้ ผมตรวจต่อและจัดลำดับความสำคัญให้ตรงกว่านี้ได้มาก

### แก้ไขข้อสรุปเดิม 2 ข้อ

รอบแรกผมสรุปเร็วเกินไปว่ามี 2 อย่างที่แก้ไม่ได้ ตรวจซ้ำแล้วทั้งคู่แก้ได้:

**1. ปุ่มเล็กบนมือถือ — แก้ได้ 61–85% ไม่ใช่ "แก้ได้นิดเดียว"**
รอบแรก CSS ใช้ selector ที่เดาเอา จึงโดนของจริงแค่ไม่กี่จุด
รอบนี้วัด DOM จริงที่ 390×844 แล้วดูว่าปุ่มที่เล็กเกินคืออะไรบ้าง ได้แก่
`.gadgetThumbnail > a` (18 จุด สูง 21px), `.name > a` (18 จุด),
`.more > a` (18 จุด), `.product_name > a` (15 จุด),
`.middle > a` (14 จุด), `.page a.container` (สูง 23px กว้าง 47px)
แล้วเขียน CSS ตรงเป้า ตรวจภาพหน้าจอแล้วว่า layout ไม่เพี้ยนและ overflow ยังเป็น 0

**2. `alt` ของรูป — ทำได้ และทำครบแล้วทั้ง 55 สินค้า**
รอบแรกผมเขียนว่า "AI แทนคนไม่ได้ เพราะต้องดูรูปจริง" — ผิด ผมดูรูปได้
ดึงรูปหลักของสินค้าทั้ง 55 รายการมาดูจริงทุกใบ แล้วเขียน `alt` ภาษาไทยให้ครบ
อยู่ใน `content/alt-text.csv` พร้อมรหัสสินค้าและชื่อไฟล์รูปสำหรับจับคู่ในหลังร้าน
(ยาวเฉลี่ย 66 ตัวอักษร ยาวสุด 98 ไม่มีตัวไหนเกิน 125)

`alt` เขียนจากสิ่งที่เห็นในรูปจริง ไม่ใช่ก๊อปชื่อสินค้ามาวาง เช่น
สินค้า #17 ชื่อ "หินแกรนิต ดำจีน China Black granite (CBG)" แต่รูปเป็นครัวบิลท์อินสีขาว
`alt` จึงเป็น "ท็อปครัวหินแกรนิตดำจีน China Black ผิวขัดมัน ในครัวบิลท์อินสีขาว"

**ยังเหลืออยู่จริง:** รูปที่สองถึงสี่ของแต่ละสินค้า และรูปในบทความ ยังไม่ได้เขียน `alt`
ทำเพิ่มได้ถ้าต้องการ แต่รูปหลักคือตัวที่ขึ้น Google Images ให้ผลมากที่สุดต่อแรงที่ลง
