# 说吧 · พูดจีนได้

แอปเรียนภาษาจีนไทย–จีน **เน้นพูด ไม่เน้นเขียน** สำหรับคนทำธุรกิจอสังหาริมทรัพย์
วัสดุก่อสร้างและตกแต่ง ที่ต้องไปจีนบ่อยเพื่อดูงานและซื้อของ

เป็น Progressive Web App — ติดตั้งลงมือถือได้ **ใช้งานได้ครบแม้ไม่มีอินเทอร์เน็ต**
ไม่ต้องผ่าน App Store ไม่ต้องใช้ VPN ในจีน

---

## ทำไมไม่ยึด HSK

คุณบอกว่าไม่ได้เรียนเพื่อสอบ แต่เพื่อไปคุยกับคนจีนและต่อรองซื้อของ — HSK จึงเป็นกรอบที่ผิด

คำที่คุณต้องใช้จริงหน้าโรงงาน อย่าง **起订量** (MOQ), **出厂价** (ราคาหน้าโรงงาน),
**货期** (ระยะเวลาส่งของ), **验货** (ตรวจสินค้า), **尾款** (เงินงวดสุดท้าย),
**色差** (สีเพี้ยน), **坑距** (ระยะท่อชักโครก) — **ไม่มีคำไหนอยู่ในบัญชีคำศัพท์ HSK เลย แม้แต่ HSK 6**

แอปนี้จึงใช้ HSK เป็นเพียงแกนของ *ความยากไวยากรณ์* (ระดับ 1–5 ในข้อมูล)
แต่เลือกคำศัพท์จาก *สถานการณ์จริง* ของสายงานคุณ

## โหมดการเรียน

- **บทเรียนวันนี้** — ระบบทวนอัตโนมัติ (SRS) เลือกให้เองว่าวันนี้ควรทวนคำไหน
  คำที่คุณเกือบลืมจะถูกดันขึ้นมาก่อน คำที่แม่นแล้วจะทิ้งช่วงยาวขึ้นเรื่อยๆ
- **ฝึกพูดรัว** — เห็นความหมายไทย → พูดจีนออกมา → ไมค์ให้คะแนน 0–100%
  (ให้น้ำหนักประโยคมากกว่าคำเดี่ยว เพราะเป้าหมายคือพูดได้ ไม่ใช่ท่องศัพท์)
- **ฟังจับใจความ** — ฟังเสียงจีน เลือกความหมาย ฝึกหูซึ่งเป็นด่านจริงเวลาคุยกับคนจีน
- **บทสนทนา** — เล่นเป็นตัวคุณเอง ฟังอีกฝ่ายพูด แล้วพูดตอบกลับ
- **คลังคำ** — ค้นหาได้ทั้งภาษาไทย จีน และพินอิน (พิมพ์ `jiage` หรือ `MOQ` ก็เจอ) เปิดดูก่อนเข้าห้องเจรจา

## ติดตั้งลงมือถือ

1. เปิดลิงก์แอปในเบราว์เซอร์
   - **iPhone → ต้องเป็น Safari** (ดูเหตุผลในหัวข้อข้อจำกัด)
   - **Android → Chrome**
2. iPhone: กดปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
   Android: เมนู ⋮ → **ติดตั้งแอป** / **เพิ่มไปยังหน้าจอหลัก**
3. เปิดจากไอคอนบนหน้าจอโฮม จะได้เต็มจอเหมือนแอปจริง

### เปิดเสียงภาษาจีน (ทำครั้งเดียว จำเป็น)

- **iPhone/iPad** — ตั้งค่า › การช่วยการเข้าถึง › เนื้อหาที่พูด › เสียง › **ภาษาจีน (แมนดาริน จีนแผ่นดินใหญ่)** แล้วโหลดเสียงลงเครื่อง
- **Android** — ตั้งค่า › ระบบ › ภาษาและการป้อนข้อมูล › เอาต์พุตแปลงข้อความเป็นคำพูด › ติดตั้งข้อมูลเสียง › **中文 (จีน)** แล้วเลือกดาวน์โหลดเพื่อใช้ออฟไลน์

โหลดแล้วเสียงอ่านจะทำงาน**ได้แม้ไม่มีเน็ต**

## ข้อจำกัดที่ต้องรู้ (ไม่ขายฝัน)

**การให้คะแนนด้วยไมค์บน Chrome/Android ต้องต่ออินเทอร์เน็ต** — เพราะ Chrome ส่งเสียงไป
ประมวลผลที่เซิร์ฟเวอร์ของ Google ในจีนที่เข้า Google ไม่ได้ ฟีเจอร์นี้จะใช้ไม่ได้ถ้าไม่มี VPN
เมื่อเกิดกรณีนี้ แอปจะแสดงปุ่ม **"ให้คะแนนเอง"** ให้แทน ไม่ล็อกการเรียน

**บน Safari/iOS ใช้ระบบรู้จำเสียงของ Apple ซึ่งมักใช้งานได้ในจีน** — ถ้าคุณใช้ iPhone
ให้เปิดแอปนี้ด้วย Safari จะได้ฟีเจอร์ไมค์ครบที่สุดตอนอยู่จีน

ส่วนที่เหลือทั้งหมด — เสียงอ่าน 🔊 การทวน คลังคำ บทสนทนา สถิติ — **ใช้ได้ออฟไลน์ 100%**

**คำอ่านไทยเป็นแค่ทางลัดตอนเริ่ม** ภาษาไทยไม่มีเสียง zh / ch / sh / r และสระ ü จริงๆ
ให้ยึดเสียงจากปุ่ม 🔊 เป็นหลักเสมอ กติกาคำอ่านที่ใช้ในแอป:

| วรรณยุกต์จีน | เทียบเสียงไทย | ตัวอย่าง |
|---|---|---|
| เสียง 1 (ˉ) | สามัญ | mā → มา |
| เสียง 2 (ˊ) | จัตวา | má → หมา |
| เสียง 3 (ˇ) | เอก | mǎ → หม่า |
| เสียง 4 (ˋ) | โท | mà → ม่า / ม้า |

## เพิ่มคำเอง

แก้ไฟล์ใน `js/data-*.js` แล้วเพิ่มรายการตามรูปแบบนี้:

```js
{
  i: 'm999',              // id ห้ามซ้ำ
  u: 'mat.tile',          // หมวด (ดูรายการหมวดใน js/data.js)
  z: '起订量',             // ภาษาจีน
  p: 'qǐ dìng liàng',     // พินอิน
  t: 'ฉี่ ติ้ง เลี่ยง',    // คำอ่านไทย
  m: 'ยอดสั่งซื้อขั้นต่ำ',  // ความหมาย
  k: 'w',                 // 'w' = คำ, 's' = ประโยค
  l: 4,                   // ระดับความยาก 1–5
  n: 'โน้ตเพิ่มเติม'       // ไม่ใส่ก็ได้
}
```

จากนั้นแก้ `CACHE` ใน `sw.js` เป็นเลขใหม่ (เช่น `zhth-v2`) เพื่อให้เครื่องที่ติดตั้งไว้ดึงเวอร์ชันใหม่

## เผยแพร่ผ่าน GitHub Pages

เปิด Settings › Pages ของ repo นี้ แล้วเลือก branch ที่ต้องการเผยแพร่ (root)
แอปใช้ path แบบสัมพัทธ์ทั้งหมด จึงทำงานได้ถูกต้องบน URL ย่อยแบบ
`https://<user>.github.io/<repo>/`

รันในเครื่องเพื่อทดสอบ:

```bash
npx http-server -p 8199 -c-1 .
# แล้วเปิด http://127.0.0.1:8199/
```

> Service Worker ต้องการ HTTPS หรือ `localhost` เท่านั้น — เปิดไฟล์ด้วย `file://` จะไม่ได้โหมดออฟไลน์

## โครงสร้างโปรเจกต์

```
index.html               โครงหน้าจอทั้งหมด
css/style.css            ธีม รองรับโหมดมืดอัตโนมัติ
js/data-core.js          คลังคำ: ชุดแกน
js/data-daily.js         คลังคำ: ชีวิตประจำวันในจีน
js/data-materials.js     คลังคำ: วัสดุก่อสร้างและตกแต่ง
js/data-dialogues.js     บทสนทนาจำลอง
js/data.js               รวมคลังคำ + ข้อมูลหมวด + ดัชนีค้นหา
js/srs.js                ระบบทวนอัตโนมัติ + เก็บความคืบหน้าใน localStorage
js/speech.js             เสียงอ่าน (TTS) + ฟังเสียงและให้คะแนน (ASR)
js/app.js                ตรรกะหน้าจอทั้งหมด
sw.js                    Service Worker สำหรับใช้งานออฟไลน์
tools/make_icons.py      สร้างไอคอน PNG (ไม่ต้องพึ่งไลบรารีภายนอก)
```

ไม่มี build step ไม่มี dependency ไม่มี CDN — เปิดไฟล์แล้วทำงานได้เลย
(สำคัญ เพราะ CDN หลายเจ้าถูกบล็อกในจีน)

ความคืบหน้าเก็บใน `localStorage` ของเครื่องคุณเท่านั้น ไม่มีการส่งข้อมูลออกไปไหน
ย้ายเครื่องได้ด้วยปุ่ม **สำรองข้อมูล / กู้คืนข้อมูล** ในหน้าตั้งค่า
